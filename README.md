# 21 Day Challenge Tracker V2
 
Simple one-page tracker.

Features:
- Two editable names
- Editable challenge start date
- Default tasks: Study/Coding, Exercise, Entertainment, Communication, Applications
- College can be assigned to any day
- Weekly Project automatically appears on Saturday and Sunday
- Editable default tasks
- 21-day progress
- Current/next month calendar
- Calendar updates when a day is partially/completely completed
- Daily notes
- Browser localStorage

Open index.html to run it.

For shared online data between devices, replace localStorage with Firebase Firestore in the next deployment step.
